# PRD: Vibe Landing Project 🌊

**Статус:** В разработке (Локально)  
**Автор:** Dimash  
**Концепция:** Переход от геймдева (Pygame) к современному вебу. Чистый минимализм.

---

## 1. Цель проекта
Создать эстетичный, «воздушный» лендинг для демонстрации скиллов и прошлых проектов (например, копии Undertale) своему другу и самому себе. Главный приоритет — удовольствие от процесса и чистота кода.

## 2. Целевая аудитория
* Я сам (для закрепления React).
* Лучший друг (похвастаться вайбом).

## 3. Стек технологий
* **Framework:** React (Vite) — за мгновенный рестарт и скорость.
* **Styling:** Tailwind CSS — для верстки «на лету» без боли в CSS-файлах.
* **Icons:** Lucide-React — тонкие линии, идеально для минимализма.
* **Deployment:** Локальный запуск (`npm run dev`).

## 4. Функциональные требования (MVP)
1. **Hero Section:** Большой заголовок, краткое описание "кто я", и кнопка-призыв.
2. **Projects Grid:** Карточки проектов. Минимум текста, максимум стиля. 
   - *Обязательно:* Блок про Undertale на Pygame.
3. **Vibe Toggle:** Переключатель темной/светлой темы (опционально, но добавляет +100 к вайбу).
4. **Footer:** Ссылки на соцсети или просто лаконичная фраза внизу.

## 5. Дизайн-система (Minimal Style)
* **Цветовая палитра:** - Фон: `#FFFFFF` или очень глубокий темно-серый `#0F172A`.
    - Акцент: `#6366F1` (Indigo) или классический черный.
* **Типографика:** Без засечек (Inter / Sans). Большие межстрочные интервалы.
* **Принципы:** - Минимум теней (или их полное отсутствие).
    - Плавные микро-взаимодействия (hover-эффекты).
    - "Negative Space" — даем элементам дышать.
